\problemname{Spotify Connect}

Spotify has just launched the new feature Spotify Connect, which enables a
user to remotely control their playback from their mobile phone. This brings a
number of new technical challenges, and one of them is how the logging of playback data is done.
In order to report to the record labels, one must know exactly how long
a user has been listening to music.

You will receive log data for the \texttt{play} and \texttt{paus} button presses
for a user. The user uses both their laptop to control the music, but
also sometimes remotely controls it with their mobile phone via Spotify Connect. The logs contain both
the computer's and the mobile's \texttt{play} and \texttt{paus} button presses. When the user presses
on the mobile there is exactly $100$ milliseconds of delay until the laptop
(where the music is played from) reacts. Your task is to
determine exactly how many milliseconds in total the laptop was playing music.
Before the first command is executed, the player is in a paused state.

\section*{Input}
The first line contains the integer $1 \le N < 1000$, the number of log lines.

The following $N$ lines contain a list of logs. The logs come
in the order button presses occur with a timestamp in milliseconds, unit
(\texttt{laptop} or \texttt{mobile}) and command (\texttt{play} or \texttt{paus}). The
last log will
always be a \texttt{paus} command. Furthermore, two logs will never have the same
timestamp or be exactly 100 milliseconds apart.

To make the input extra readable, the fields of the log lines are
aligned. The timestamp is padded with zeros on the left so that the number
is always 7 characters long, and mobile is spelled mobile, i.e. with the same
number of characters as laptop. See the input example.

\section*{Output}
Your program should output a single integer -- the number of milliseconds the user listened to music.

\section*{Explanation of Samples}
In the first input example, the user plays for 500 milliseconds. Then they use
the mobile to start the music and stop it from the laptop $500$ milliseconds
later, but due to the delay the music only plays for 400 milliseconds.
In total the music plays for $900$ milliseconds.
