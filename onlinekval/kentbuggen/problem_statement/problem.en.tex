\problemname{The Kent Bug}

In Spotify, problems can arise if multiple artists have the same name. Given a list of artists, determine how many artist names are affected by this problem.

\section*{Input}

The first line consists of an integer $n$ ($1 \leq n \leq 10^5$) -- the number of artists. Then follow $n$ lines with one artist name per line. Artist names are strings consisting of lowercase letters (a-z) with at most 20 characters.

\section*{Output}

Output an integer $m$ -- the number of distinct artist names that appear more than once.

\section*{Explanation of Samples}

In the first example there is exactly one name that appears more than once -- \texttt{kent}. Therefore the answer is 1.
