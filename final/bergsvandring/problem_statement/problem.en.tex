\problemname{Mountain Hiking}

\begin{figure}[ht!]
\centering
\includegraphics[width=0.4\textwidth]{berg.pdf}
\caption{The appearance of the mountain in the examples. The red segments have too steep a slope to walk on. The dashed blue lines are bridges built by the hikers.}
\label{overflow}
\end{figure}

A mountain range consists of $n$ points, ($x_1$, $y_1$) to ($x_n$, $y_n$), where $x_1 < x_2 < ... < x_n$. Between point $i$ and point $i+1$ a line segment is drawn.

Some hikers want to traverse the entire mountain range, i.e. walk from point $1$ to point $n$. However, they cannot walk on a line segment if its slope is strictly greater than $d$. Here we define the slope of the line through ($x_i$, $y_i$) and ($x_j$, $y_j$) as

$$
\frac{|y_i - y_j|}{|x_i - x_j|}
$$
where $|x|$ denotes the absolute value of $x$.

To make the hike possible they can build bridges in the mountain range. A bridge is also represented as a line segment and is always built between two points $i$ and $j$. A bridge must of course not have a slope greater than $d$, and furthermore it is not possible to build a bridge that passes through the mountain anywhere.

Determine the minimum total length of the bridges that need to be built to make the hike possible.

\section*{Input}
The first line contains the integer $n$ and the floating-point number $0 < d \le 10^5$, separated by spaces.
The following $n$ lines contain two integers $0 < x_i, y_i \le 10^6$, the coordinates of point $i$, also separated by spaces. It is guaranteed that $x_i < x_{i+1}$.

\section*{Output}
Output a floating-point number -- the minimum total length of bridges needed to make the hike possible.
If it is impossible to complete the hike regardless of how the bridges are built, output $-1$ instead.

\section*{Precision}
An answer to this problem will be considered correct if the absolute error is less than $10^{-3}$. It is guaranteed that the result for a test case is not affected by a \emph{small} change of the number $d$ (this is to avoid precision errors when comparing floating-point numbers).

\section*{Scoring}

Your solution will be tested on a set of test groups. To earn points for a group,
you must pass all test cases in that group.
