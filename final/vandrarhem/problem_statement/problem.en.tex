\problemname{Hostel}
Arash is organizing an onsite final for PO, the Potato Peeling Olympiad. There will be
$N$ participants and Arash now needs to book accommodation for the contestants. Arash has set his sights
on a nearby hostel to book the beds that are needed.

There are $M$ types of beds. For a given bed type $i$, a bed
costs $c_i$ kronor and there are $b_i$ available beds of that type. The hostel has
no current bookings, so it is perfectly fine to book as much as
needed.

The Swedish Potato Peeling Olympiad is not very good at math, and
now needs your help. They want to know the minimum possible cost of booking
the beds that are needed at the hostel. Can you help them?

\section*{Input}
The first line consists of two integers, the number of participants $N$ ($1 \leq N \leq 100$)
and the number of bed types $M$ ($1 \leq M \leq 5$). Then follow $M$ lines, each
with the numbers $c_i$ ($100 \leq c_i \leq 1000$) and $b_i$ ($1 \leq b_i \leq 100$) as
described above.

There will always be enough beds for all participants.

\section*{Output}
Output a single integer on a line: the minimum possible cost for the Swedish Potato Peeling Olympiad to rent
at the hostel for one night.

\section*{Explanation of Samples}
Let us explain the first input example. You buy all $8$ cheapest
beds for a total cost of $2400$, then you buy two of the slightly more expensive
beds for a total cost of $1000$. The final price is $3400$.

\section*{Scoring}
Your solution will be tested on a set of test groups. To earn points for a group,
you must pass all test cases in that group.
